Standalone integration tool to deploy interactive Civic_Twin instances inside your WordPress community.

== Description ==

Civic_Twin Plugin V.4.0.1 bridges the gap between physical urban planning dashboards and public community sites. Created by Angel Sharks, this plugin provides automated installation, rapid member page setups, and responsive canvas shortcodes.

== Features ==
* **Rapid Installation Configurator:** Securely link to your local hosting environment or public shard dashboard with single-click diagnostics.
* **Automated Page Builder:** Instantly generate Member registration pages, Full Dashboard portals, and high-performance Leaflet spatial map displays.
* **NIST layer Integration:** Access detailed Energy, Water, Transit, and Safety indexes live.
* **B-LAN Shard Support:** Local mesh network telemetry and resilient synchronization fallback.

== Installation ==
1. Upload `civic-twin-wp-plugin.zip` to the `/wp-content/plugins/` directory, or install directly through the WordPress plugins dashboard.
2. Activate the plugin.
3. Navigate to **Civic Twin Hub** in the left-hand WordPress menu.
4. Input your **Instance Dashboard URL** and click "Test Connection & Diagnostics" to verify synchronicity.
5. Go to **Member Pages** to create or repair required layout portals.

== Shortcodes ==
* `[civic_twin_dashboard]` - Embeds the main dashboard matrix.
* `[civic_twin_map]` - Embeds the full-bleed Leaflet GIS map.
* `[civic_twin_member_portal]` - Embeds the CID Member Gateway and B-LAN diagnostic metrics.
